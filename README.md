# 有余记账

**收支有数，生活有余。**

一款以手绘小镇为首页的 Android 本地记账应用。本仓库提供安装包与版本说明，暂不公开源码。

## 安装

1. 下载上方 APK，打开后按 Android 提示允许当前下载来源安装应用。
2. 已安装同签名体验版的用户，可直接覆盖安装；升级前建议在设置中导出本地备份。
3. 若提示签名冲突，请勿直接卸载，先保留本地备份并反馈问题。
4. 首次打开可从操作指南了解入账流程，按需开启通知或悬浮识别权限。

## 功能

- 手动记录收入与支出，管理多个账本；入账时账户可选。
- 查看流水、统计和预算，管理存钱计划。
- 管理账户、转账、还款与退款，回收站支持恢复记录。
- 支持图片补记、账单文件导入，以及本地备份与恢复。
- 按渠道开启支付通知识别，也可主动使用悬浮入口识别账单页面，再核对入账。
- 首页动态可关闭，应用内提供图文操作指南。

## 较上一版更新

1. 首页加入左上、左下、右下三处同步微风动画。
2. 小鸟随机飞入、落脚与飞出，加入张望、啄笔、整理羽毛和抖羽动作。
3. 设置增加“首页动态 → 减少动态效果”，可切回静态首页。
4. 动画在离开首页、失去窗口焦点或进入后台时暂停；装饰层不拦截按钮点击。
5. 使用异步解码、相邻帧预取和有上限的缓存，减少重复绘制。

## 使用说明

这是开发体验版，使用现有体验包签名与包名（app.youyu.ledger.preview），不是应用商店正式版。模拟器仍存在慢帧，真机流畅度、耗电和发热待验证；可在设置中开启“减少动态效果”。支付通知、悬浮识别受权限、渠道页面与系统后台限制影响，仍需实机验证，识别后请核对金额、类型和账户。

账务数据保存在本机，请自行保管导出的备份。反馈问题时请遮挡订单号、账号等个人信息；不要将真实账单上传到公开 Issue。

# 有余记账 v1.0.0-rc.14

新增理发分类，完善历史账单的本地自动分类。

- “理发”独立于美容，使用与现有分类相配的彩铅剪刀、梳子图标。
- 便利店、超市和普通网购商品默认归“购物”；保留日用、服饰等细分类供手动调整。
- 补充明确餐饮、运营商充值、订阅服务、短期会员、医疗及虚拟道具规则。具体服务优先于商品大类，不明确的交易仍留待分类。
- 自动分类只补齐待分类项，不覆盖用户已选分类；已有导入记录可批量调整，无需重复导入。
- 兼容旧版自定义“理发”分类，避免重复显示和备份校验失败。

版本号 93，正式包名与上一版签名一致，可覆盖升级。数据库版本保持 17。包含 rc.13 的固定导入按钮、批量核对入账及可能重复提醒。

# 有余记账 v1.0.0-rc.15

待确认记录支持列表快捷删除和导入记录批量删除。

- 普通待确认及文件导入记录右侧增加垃圾桶，复用流水页的砖红色删除图标。
- 导入批次支持“选择本批可能重复项”，只选中供核对，不自动删除。
- 底部增加“删除所选”，确认笔数后整批处理。不影响已入账流水，不进入回收站；保留去重标记，避免同一来源重复导入。
- 周期记账保留“跳过本期”，不改变未来期次。
- 删除前校验记录状态，中途失败整批回滚，防止过期界面删除已修改或已入账记录。

版本号 94，正式包名、签名、数据库版本、OCR 引擎和处理器支持范围与 rc.14 一致，可覆盖升级。

验证：103 项核心测试通过；Android 9 独立指南安装通过批量删除回滚、过期记录拦截、已入账流水保留、重新导入去重测试；模拟器使用虚构数据从 97 笔中选中本批 96 笔可能重复项并确认删除，剩余另一批 1 笔保持不变。Release 构建、关键 Lint 和签名检查通过。未提交应用市场审核或云测。

# 有余记账 v0.2.70

> 拼多多商品区域 OCR 补充备注

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.69。

[下载 youyu-v0.2.70.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.70/youyu-v0.2.70.apk) · 可覆盖安装。

## 本次更新

- 拼多多无障碍已读取金额、缺少商品备注时，定位实付行相邻的商品卡片，仅裁剪该区域及实付行做 OCR 补充。
- 裁剪图实付金额须与无障碍结果一致，商品文字须通过位置、内容及可信度检查；补充仅修改缺失备注，保留原金额和日期。
- 区域无法明确定位或文字不可靠时保留原字段，避免把推荐商品和操作按钮写入备注。
- 诊断区分商品区域 OCR 与整屏 OCR，显示备注是否补充成功。

## 说明

- 无障碍仍优先；本次针对拼多多缺备注场景，不是所有平台的 OCR 重写。
- 手写字体仍可能识别失败或出现错字，请核对后入账。此时可手填备注，或使用“始终留空”。
- 验证：79 项核心测试通过，独立指南应用中的无障碍及区域定位检查通过；尚未经用户手机上的手写体订单实测。

# 有余记账 v0.2.58

> 调整分类排序样式，避免淘宝跨订单字段混入

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.57。

[下载 youyu-v0.2.58.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.58/youyu-v0.2.58.apk) · 通用 APK，可覆盖安装。

## 本次更新

- 分类排序的支出、收入选中态改为双下划线；上下移动改用矢量箭头图标。
- 去掉分类图标页面顶部的分类管理介绍卡。
- 淘宝悬浮识别改用当前截图提取字段，不再直接采用可能混入其他订单的无障碍金额和备注。
- 截图未识别的字段留空，仍打开核对面板；不回填未经核实的旧页面字段。
- OCR 未找到整单金额标题时，可读取明确标注的实付价；多个金额不同则留空供核对。

## 验证与限制

- 68 项核心测试通过，包含连续订单字段独立性、空结果、实付价与整单金额优先级。
- 两张不同订单截图的只读 OCR 金额复测通过，未写入账本。
- 独立指南应用已检查双下划线和箭头图标。
- 淘宝每次多一次截图识别，手写字体仍可能造成缺失；日期、备注不明时需手动补填。尚需真机核对连续切换订单的完整流程。

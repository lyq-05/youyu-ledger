# 有余记账 v1.0.0-rc.10

新增微信、支付宝原始对账文件导入，无需手工改为有余 CSV 列名。

- 支持微信 XLSX／CSV、支付宝 CSV（UTF-8／GB18030），保留有余 CSV 模板。
- 自动定位交易表头，支持 Excel 日期、共享字符串及数值金额；预览后才放入当前个人账本的待确认。
- 按平台交易单号识别重复导出；已有记录不覆盖。与手工、自动识别产生的账目仍需人工核对，不能保证跨来源去重。
- 退款、还款、不计收支、充值提现、零金额和未确认状态会列明未导入原因，需另行处理；本版不是完整的平台历史账本自动迁移。
- 每次最多 1000 笔、10 MB；ZIP 需先解压，不支持 PDF、旧版 XLS、加密工作簿或公式账单。
- 设置搜索增加“微信、支付宝、Excel、历史账单”等关键词。
- 保留 rc.9 的 Android 8–9 数据库关闭兼容修复，正式包名、签名及数据库版本不变，可覆盖升级。

验证：101 项核心测试通过；Android 9 独立指南应用通过 Excel 解析、仅写待确认及重复导入／重新打开数据库后的去重测试，文件选择和预览界面已检查。正式签名包在 Android 9 模拟器启动成功。真实原始账单仅本地分析，未进入源码、测试素材或安装包。

本包未重新运行 vivo 云测，也未重新提交商店审核。版本号 89，最低 Android 8.0（API 26）。

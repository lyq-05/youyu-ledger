## 本次更新

- 自动记账、悬浮记账分别集中在一张纸面设置区；低频设置折叠，展开箭头使用图形。合并支付通知的授权与连接入口，说明通知读取、状态通知与核对小窗的不同用途。
- 无障碍页面识别与通知识别并列；OCR仍为默认关闭的补充项。研发字段排查工具不向正式包用户开放。
- 主动点击悬浮伙伴时先读无障碍文字，字段足够则直接核对；仅在需要截图补充时申请屏幕共享，授权后回到账单再次点击，重新读取当前页面。关闭伙伴后丢弃迟到结果。
- 本地识别历史由12条扩大为最近24小时、最多600组；短时连续重复结果合并，记录当时的开关、授权及服务状态。容量满后仍会覆盖，并非完整交易日志。旧记录单独标注，无年份或权限信息时不补造；首次读取后额外保留24小时。
- 反馈表单明确说明“预览反馈”自动附诊断，输入可留空；提示填写支付时间，移除长反馈编辑时截断记录的问题。仅由用户主动复制，不自动发送。
- 新增8种森林伙伴：首页和设置可进入；松鼠默认拥有，首次30装扮金币，每日签到10金币，其余伙伴各100金币。兑换后可作为悬浮形象，随本地备份恢复。暂未接入广告、充值、服装配件或会员。
- 存钱计划用对应动物食物插画表现进度，始终保留真实金额；装扮金币不用于记账或存钱金额换算。自动与悬浮识别不消耗金币。
- 账户明细行间距对齐流水；伙伴入口文字与纸面风格统一，动物选择网格适配窄屏与大字体。
- 修正悬浮无障碍设置的搜索名称，使其与页面定位一致。

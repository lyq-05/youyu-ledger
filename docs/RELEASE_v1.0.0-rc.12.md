# 有余记账 v1.0.0-rc.12

修复微信／支付宝历史账单解析成功，但点击“确认导入待确认”出现 `SQLITE_BUSY`、未生成待确认记录的问题。

- 导入和分类读取共用同一数据库连接，避免事务阻塞自身。
- 已有平台交易标识继续跳过；其他写入失败会整批回滚，避免被误报为重复记录。
- 增加任务入口防重复点击，并将锁忙错误改为可理解的重试提示。
- 保留 rc.11 的账单下载指引及此前功能。退款、还款、不计收支等仍需另行核对；不保证与手工／自动识别记录跨来源去重。

版本号 91，最低 Android 8.0。正式包名、签名和数据库版本不变，可覆盖升级，无需卸载。

验证：101 项核心测试通过；Android 9 独立指南应用通过同文件非 WAL 导入、34/96 笔虚构数据、重复导入、失败回滚和重开持久化测试；UI 实际导入虚构微信 XLSX 和 96 笔支付宝 CSV 后均能进入待确认。Release 构建、关键 Lint 和签名核验通过。

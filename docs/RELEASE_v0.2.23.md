# 有余记账 v0.2.23

> 识别场景卡片、运行状态与后台指引

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.23.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.23/youyu-v0.2.23.apk) · 136.0 MB

## 本次更新

- 自动记账顶部汇总暂停、未选渠道、通知及页面服务状态，区分未授权与已授权未连接。
- 新增后台运行指引：本应用通知显示、电池优化和省电状态，以及系统设置入口；说明厂商自启动、后台运行和后台锁定需按机型检查。
- 渠道开关移至“设置 → 自动记账 → 识别场景”独立内页，13 个应用/渠道以卡片展示范围与验证状态，四个已接入渠道开关即时保存。
- 未接入项仅展示缺口，不提供无效开关；区分商家应用与实际支付渠道，历史详情继续主动悬浮补记。
- 更新指南截图与步骤；整理场景缺失清单和优先级。

## 范围说明

本版完善信息展示，没有新增支付渠道的解析规则。支付宝通知已有部分真机成功反馈，微信截图兜底仍待真机验证；其他已有规则不能视为所有页面都受支持。

未接入项包括美团支付、抖音支付、云闪付、多多支付等；商家跳转支付宝/微信付款按对应渠道处理。后台设置不能保证服务永久在线，所有识别结果仍需核对后入账。

## 验证与限制

独立 guidecapture 安装中检查场景卡片、导航和开关持久化，指南仅使用虚构数据。编译、APK 签名及覆盖安装通过。通知设置与电池优化入口打开成功。

当前 Android 16 模拟器的系统省电设置缺少 flipendo 组件，打开该系统页面会报错；此项不能算通过，厂商入口仍需真机验证。本版未修改识别算法，未重复运行整套识别回归。

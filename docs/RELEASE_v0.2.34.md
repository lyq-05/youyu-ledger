# 有余记账 v0.2.34

> 通知服务自动恢复与独立成功记录

**开发体验版** · Android 8.0+ · 上一版 v0.2.33，同签名覆盖安装。

[下载 youyu-v0.2.34.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.34/youyu-v0.2.34.apk)

## 本次更新

- 已开启自动记账且已授权通知使用权时，返回应用主动检查通知连接。未连接则在一轮内最多提交3次重连请求，并等待系统连接确认。
- 自动请求限频，连接成功、暂停自动记账或撤销权限后停止重试；可在设置中点击“通知服务”手动再试。不自动切换系统授权开关。
- 设置与复制诊断新增“通知连接记录”，区分请求已提交、实际连接成功与多次请求后仍未连接。
- 单独保留“最近成功识别”的时间和入口：通知、无障碍事件来源、无障碍窗口根或截图OCR。后续空页面、识别失败及重复结果不会覆盖最近成功。

## 如何使用

覆盖安装后打开应用；在“设置 → 自动记账”查看通知服务和连接记录。成功以系统连接回调为准，请求重连不等于已连接。如果系统仍未恢复，可手动再试或最后关闭再开启通知使用权。

下次消费后可直接查看“最近成功识别”，不必从大量空页面记录中寻找成功瞬间。此处成功表示生成待确认，仍需核对保存才入账，也不代表小窗实际可见。

## 已知限制

不同手机对后台服务的限制不同，不能保证所有覆盖安装或重装场景均自动恢复。卸载后权限需以系统实际授权为准。本版不改变已经验证的拼多多→微信事件来源识别规则。

# 有余记账 v0.2.27

> 自动识别截图调试

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.27.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.27/youyu-v0.2.27.apk)

## 本次更新

- 设置 → 自动记账新增“保留自动识别截图（调试）”，默认关闭。需同时开启自动截图 OCR；开启后仅本机保留最近 3 张实际送入 OCR 的原图。
- 可查看截图时间、截图方式、窗口编号和识别结果，并切换或清除图片。关闭开关也会清除，清除后仍在执行的旧任务不会重新写回图片。
- 图片位于应用私有且排除系统备份的目录，不上传、不加入账本备份。截图可能含账单或其他页面信息，请在排查结束后关闭。
- 包含 v0.2.26 修正：安装名称乱码、已接入渠道默认选中、截图至少间隔 8 秒并合并保留一次冷却重试、独立显示最近截图结果。
- 更新应用内操作指南。

## 验证与限制

独立 guidecapture 安装验证原图字节一致、最近三张保留、清除后旧任务拒绝写回、实际截图及 OCR 结果关联、关闭清除，并检查查看界面。全部使用虚构测试画面。

文字节点读取本身不会产生截图，系统截图失败也不会有对应图片，请结合“最近截图结果”查看。微信真实支付问题仍待实际画面定位，不能认为本版已修复识别；多多支付尚未接入。

无需卸载，直接覆盖安装。未确认的识别结果不会自动入账。

# 有余记账 v0.2.65

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.64。

## 本次更新

- 手动采集字段诊断时，增加窗口类型、活动状态、选中根及节点结构，帮助定位订单正文缺失。
- 记录不可见节点的文字数量及是否含字段标签，不导出隐藏正文，不用于填账。
- 延续无障碍优先策略，本次不增加等待或重试次数。

## 验证与限制

- 75 项核心测试及独立指南应用的无障碍读取检查通过，包括隐藏内容与密码内容不进入诊断正文的检查。
- 本次为诊断增强，尚未确认仅返回少量节点的根因，需要在出现问题的订单页面重新采集。

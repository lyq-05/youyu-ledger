# 有余记账 v0.2.25

> 支付页面节点读取与窗口选择修正

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.25.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.25/youyu-v0.2.25.apk) · 135.9 MB

## 本次更新

- 补齐包含非重要节点、控件标识和交互窗口的无障碍配置。
- 仅在当前支付应用的活动或焦点应用窗口中选择读取目标，避免读取其他应用或输入弹窗背后的账单；核对窗口已显示时不重复读取。
- 首次读取移除原有 400 毫秒额外等待；失败后分别等待 350、900 毫秒重试。支付应用或事件窗口变化时替换旧的排队读取。
- 页面诊断增加窗口来源与窗口编号，方便继续定位空节点。

## 验证与限制

独立 guidecapture 安装中，虚构样本覆盖非重要节点、支付弹窗、输入框遮挡、切换应用、延迟文字、重复页面、OCR 限频、开关与通知去重；全部通过。APK 签名与覆盖安装通过。

微信真实支付页面是否仍返回空节点，需真机验证；不能据模拟器结果承诺已修复或立即弹出。多多支付仍未接入。本次未修改支付字段解析算法。

测试另发现安装桌面组件时，现有组件刷新存在数据库锁等待，可能影响整体速度，尚未在本版处理。

覆盖安装后，可将有余无障碍服务关闭再开启一次以重新加载配置。等待正常消费时验证即可，无需专门消费；失败时提供“最近页面读取”诊断。

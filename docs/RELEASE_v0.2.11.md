## 🚀 本次更新

1. 首页收支看板与流水统一进入明细，底部可直接切换明细、统计和账户；统计分析与预算功能继续保留。
2. 明细增加月度结余、收支汇总及按日期分组的账单列表；备注与账户为次要信息，金额右对齐。
3. 内页去掉重复的品牌名、宣传语和开发版提示；账单详情按账本、类型、账户、日期、备注排列。
4. 悬浮窗金额符号紧邻数字；日期、账本和账户改为紧凑按钮，去掉三角标记与厚重阴影。

## 验证与限制

使用独立指南安装与虚构数据，验证首页两个入口、底部三项导航、账单详情及编辑入口。悬浮窗默认日期、账本、可选账户、金额校验与保存验证通过；构建、包名和签名已核验。

不同手机系统字体与输入法仍需真机试用。日期未识别时默认今天，补录历史账单请修改日期。金额必须核对后保存。

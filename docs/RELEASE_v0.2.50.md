## 本次更新

- 新识别的商品备注使用本地规则清理明确的促销词和部分中英文重复品牌，保留平台、商品名及型号；不接入 AI，不自动改写历史备注。
- 对已识别的耳机标题清理部分功能堆叠。其他无法确定的标题尽量保留，核对时仍可编辑；不是适用于所有商品的语义摘要。
- 保存成功提示账本与日期；重复识别时显示原记录位置，并提供“查看账目”入口，打开对应账本、月份及详情。
- 待确认、回收站和已忽略状态分别提示，避免统一称为“已处理”。

48 项核心测试通过。独立指南应用使用虚构数据检查了日期确认、保存、重复记录位置、查看入口及无重复入账；发布构建通过。

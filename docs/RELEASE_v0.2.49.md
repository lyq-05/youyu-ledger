# 有余记账 v0.2.49

[下载 youyu-v0.2.49.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.49/youyu-v0.2.49.apk) · **70.5 MiB** · 通用 APK，可覆盖安装。

## 本次更新

- 支持“共减”、优惠金额、“合计”、货币符号和实付金额分别处于不同文字节点的订单格式。
- 只拼接明确的金额字段片段；遇到订单、商品或推荐等新字段停止，不把优惠金额当成实付。
- 细分实付解析失败原因：标题未匹配、金额不完整、格式无法解析、多个金额冲突、OCR 小数点缺失。

## 验证与限制

- 47 项核心测试通过，新增虚构订单的拆分字段、优惠排除和冲突检查；发布构建通过。
- 用户反馈的京东诊断已确认无障碍读取和平台匹配成功。本轮修复的是可复现的字段拆分缺口；尚未取得该手机的原始无障碍节点顺序，不能确认该笔订单已经识别成功。
- 本机对所提供截图的只读 OCR 复测出现标题误读，未将疑似标题或金额直接猜改；原图及账单内容未发布。

请在原订单详情页再次点击松鼠；如仍失败，反馈“最近悬浮识别”的具体原因。

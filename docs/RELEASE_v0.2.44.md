## 本次更新

- **按需展开搜索**：设置和明细标题栏右侧新增放大镜，点击后展开搜索，再次点击或返回即可关闭；默认不占用内容区。
- **收紧内页布局**：缩小设置条目间距与卡片内容间距，保留至少 48 dp 的设置行点击区域；明细汇总更紧凑，流水条目减少空白，大字号仍可自适应。
- **更新操作指南**：同步搜索入口、设置开关、明细、统计、账户等截图与标注，删除调试工具教程和未引用图片；全部来自独立指南应用的虚构数据。
- **指南图片压缩**：24 张图片采用宽度不超过 900 px、质量 88 的 WebP，指南资源约 4.8 MiB；完整原图保存在安装包之外。
- **安装包瘦身**：从 134.3 MiB 降至 70.5 MiB，减少约 47.6%。启用 R8 与资源压缩，关闭测试开关和常驻测试面板，保留用户主动查看的诊断与反馈入口。
- 本地中文 OCR、多架构支持与浅色彩铅素材保留。深色素材仍独立归档，不进入 APK；不增加云服务。

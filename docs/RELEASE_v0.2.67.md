# 有余记账 v0.2.67

> 拼多多数值规格备注修复

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.66。

[下载 youyu-v0.2.67.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.67/youyu-v0.2.67.apk) · 可覆盖安装。

## 本次更新

- 修复数字开头的已购规格被误当成金额而丢弃的问题，支持尺寸、容量及型号开头的文字规格。
- 支持较短的有效规格，继续排除纯数字、纯金额和操作按钮文字。
- 仍使用已购规格补充备注，不代表完整商品标题提取已经解决。

## 验证

- 用虚构数据覆盖数字开头、字母型号、短规格及无效备注，保留金额回归检查。
- 延续无障碍优先读取，未改变 OCR 或账单金额规则。

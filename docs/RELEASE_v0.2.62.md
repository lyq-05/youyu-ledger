# 有余记账 v0.2.62

> 悬浮识别字段诊断

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.61。

[下载 youyu-v0.2.62.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.62/youyu-v0.2.62.apk) · 可覆盖安装。

## 本次更新

- 设置 → 悬浮记账新增“采集下次字段诊断”“复制字段诊断”“清除字段诊断”。
- 手动开启后，10分钟内的下一次无障碍读取采集相关标签、数值、text/description 来源和节点关系。
- 地址、电话、订单号及无关文字脱敏；报告仅留在内存，不写入账本或备份，不自动上传，手动复制才进入剪贴板。
- 拼多多金额失败诊断与解析使用相同的字段预处理，修正误报“未找到标题”的情况。

## 使用方法

1. 点击“采集下次字段诊断”。
2. 回到目标订单页，点击松鼠识别一次。
3. 回到设置，点击“复制字段诊断”，粘贴给开发者。
4. 可清除诊断；应用进程退出后报告也会丢失。

## 验证与限制

- 74 项核心测试通过，覆盖字段结构脱敏、节点关系、日期保留及诊断一致性。
- 本版用于定位真机无障碍字段问题，未改变金额判断规则，不代表识别成功率已提升。
- 需要无障碍服务已连接；只取得 OCR 时不会产生节点报告。

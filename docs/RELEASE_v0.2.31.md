# 有余记账 v0.2.31

> 提前微信空文字页面的截图识别

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.31.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.31/youyu-v0.2.31.apk)

## 本次更新

- 开启微信自动截图后，首次读取页面无文字且没有输入控件时即尝试截图，不再先等待两轮节点复查（原固定等待约1.25秒）。
- 识别进行中的页面请求最多合并保留一次复查，减少首次截到加载画面后漏识别的情况。
- 最近截图结果增加截图、图像准备、OCR、结果处理与本轮合计耗时。合计从本轮截图请求开始计算，不代表付款到弹窗的全部时间。
- 保留2秒截图最短间隔、串行处理、页面访问校验和同次访问去重；可能比上一版多截到一次未完成的页面。

## 使用说明与限制

直接覆盖安装，无需卸载。需已开启支付成功页识别、微信渠道及自动截图OCR。

本次减少固定等待，不承诺每次一秒内弹出。页面加载、截图冷却、OCR及设备性能仍影响速度；识别后需核对保存才入账。

## 🚀 本次更新

1. 左上、左下和右下三处枝叶使用同一风动节奏，小鸟支持六个落脚点与多种站立动作。
2. 新增减少动态效果开关；离开首页、失去窗口焦点或切后台时暂停动画。
3. 动画层不拦截点击，使用异步解码、相邻帧预取和 16 MiB 帧缓存上限，避免重复绘制静态背景。

## ⚠️ 使用与升级说明

当前为开发体验版，使用调试签名。真实支付通知、页面读取、厂商后台策略及动画真机流畅度、耗电和温升仍需验证。识别结果需要核对后入账；自定义 CSV 导入不等于兼容支付宝或微信的原始导出文件。

同签名体验版可覆盖安装。升级前请导出本地备份；不要直接卸载来解决签名冲突。

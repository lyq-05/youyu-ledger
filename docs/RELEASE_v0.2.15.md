# 有余记账 v0.2.15

> 微信转账收入、悬浮面板选中态与备注置信度试用

**开发体验版** · Android 8.0+ · 与 v0.2.14 同包名、同签名，可以覆盖安装。

[下载 youyu-v0.2.15.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.15/youyu-v0.2.15.apk) · 124.0 MB

## 本次更新

- 主动悬浮识别支持微信转账收入的正号金额、收款状态与收款时间，日期优先取收款时间。待收款、已退还等明确未完成状态不自动填入识别结果。
- 弹窗支出／收入改回粉色双下划线，去掉玫红底。
- 分类页码保持原视图，滚动时仅更新选中态，修复页码消失、重复闪烁。
- 屏幕 OCR 的备注仅提取“商品／商品说明”字段，字段与文字行、文字片段最低置信度均须达到 0.90；低分或缺少分数留空。该门槛为试用规则，不代表 90% 正确率，仍可能误填。
- 页面文字直接读取与通知文本不经过图片 OCR，其原有备注处理保留。

## 验证与限制

23 项核心测试通过；独立指南应用验证了页码视图保留、双下划线、空白面板、金额校验、保存与取消等流程。所有测试、演示数据均为虚构。

用户提供的转账图片仅临时用于本机 OCR 诊断，识别到微信收入、金额和日期；未写入账本、素材库或安装包。真机实际页面仍需复测。备注阈值尚未经过大规模样本校准，请关注误填情况，日期及金额仍应核对后保存。

OCR 置信度接口：[ML Kit Text.Line](https://developers.google.com/android/reference/com/google/mlkit/vision/text/Text.Line)。

# 有余记账 v0.2.71

## 本次更新

- 修复“极速发货”等服务标签被通用商品规则当成备注的问题；识别到这类标签时按缺备注处理，允许进入已有补充流程。
- 完整匹配服务标签，避免误删名称中含同样词语的正常商品。
- 淘宝、拼多多指南改用经授权的真实页面局部截图，程序逐块遮挡个人信息及交易具体内容，标注商品、实付、日期和展开位置；原图不入库、不打包。
- 其余五个平台暂保留文字操作步骤，移除构造页面示例，待补真实截图。

## 验证与限制

- 80 项核心测试通过，覆盖服务标签及正常商品名。
- 保持无障碍优先、OCR 补充；本次修复错误备注，不保证缺失商品标题一定能提取。
- 手写体 OCR 仍需核对，无法可靠识别时备注可留空或手填。

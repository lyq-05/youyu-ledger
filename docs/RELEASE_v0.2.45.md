## 本次更新

- **简洁设置**：取消设置条目分隔线，保留紧凑的 44 dp 点击区域；重写识别功能说明，权限状态采用绿色、橙色、红色区分。
- **测试工具默认隐藏**：进入“设置 → 关于”，连续点击“有余记账 · 版本号”七次后显示。点击“关闭测试模式”可再次隐藏，同时关闭对照诊断、停止调试截图保留并清除所保留的截图。启用测试模式不会自动开启这些记录开关，也不会授予权限。
- **统计更直观**：月统计以日历展示每日结余，格内默认不显示小数，点击日期查看精确金额；年统计按月列出支出、收入与结余。
- **统一日期与筛选**：年月采用底部抽屉选择，日期导航使用图标；账户筛选改为列表，减少粉色按钮堆叠。
- **统一卡片与动作**：内页与桌面组件采用奶油纸面及浅绿汇总卡，编辑使用淡粉色、删除使用玫红色；部分只读弹窗用右上角关闭图标。月年汇总区与预算入口保持一致。
- **修复账单详情闪退**：移除弹窗内重复的纵向滚动容器，恢复流水条目详情查看。

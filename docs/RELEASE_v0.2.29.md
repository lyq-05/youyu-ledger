# 有余记账 v0.2.29

> 缩短自动截图冷却等待

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.29.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.29/youyu-v0.2.29.apk)

## 本次更新

- 微信自动截图最短间隔从 8 秒缩短到 2 秒，减少支付成功页被前一次截图拖住的时间。
- 保留页面文字复查、串行单任务、单次合并重试、应用/窗口/开关/账本检查，以及重复账单拦截。
- 仍由页面事件触发，不增加持续录屏或持续轮询。页面频繁变化时，截图与 OCR 次数可能比上一版增加。
- 同步设置说明和操作指南。

## 验证与限制

用户提供的成功记录中，从开始截图识别到创建核对窗口约 1.2 秒，前面存在冷却等待。2 秒是截图之间的最短间隔，不是付款到弹窗的时限；页面事件、内容加载和本机识别仍需时间。

本版不改支付字段解析。识别后仍先核对，保存后入账。无需卸载，直接覆盖安装；不必专门消费测试，后续正常使用时观察即可。

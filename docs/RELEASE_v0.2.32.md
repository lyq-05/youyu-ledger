# 有余记账 v0.2.32

> 无障碍对照诊断与已接收截图离页处理

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.32.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.32/youyu-v0.2.32.apk)

## 本次更新

- 新增“无障碍对照诊断（调试）”，默认关闭。临时比较微信事件文字、事件来源节点、活动根及对应窗口根的数量、长度、不可见文字和成功页匹配状态，并记录运行时服务配置。
- 对照结果最多本机保留12条，不保存页面正文、金额或账户内容；关闭即清除。诊断可能增加读取耗时，完成排查后请关闭。
- 截图返回时确认原支付窗口后，可在离开支付页后继续OCR并生成待确认，不再因随后切页直接丢弃。
- 截图尚未接收就离开、锁屏、关闭相关功能或切换账本，仍可能取消或丢弃。不是通知记账，不能保证支付后立即离开也能识别。
- 旧截图按原页面访问去重，不覆盖新访问的去重状态；已有核对窗时新增记录留在待确认。

## 如何排查

覆盖安装后，在“设置 → 自动记账”开启“无障碍对照诊断（调试）”。下次正常微信消费后查看“查看无障碍对照”，或“复制诊断记录”。完成后关闭开关。

本版提供定位证据，尚未证明微信字段缺失的原因，也未宣称修复了微信无障碍取字。仍保留本地OCR兜底、2秒截图最短间隔和核对后入账。

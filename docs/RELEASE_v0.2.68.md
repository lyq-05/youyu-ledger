# 有余记账 v0.2.68

> 拼多多价格标签通用分隔

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.67。

[下载 youyu-v0.2.68.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.68/youyu-v0.2.68.apk) · 可覆盖安装。

## 本次更新

- 统一分隔“该规格……价”和“合计……价”，支持拼单、秒杀、大促及其他短促销名称，避免价格明细混入规格导致备注被丢弃。
- 要求标签后紧跟数值，支持标签空格、冒号和货币符号；普通商品文字中的“价”不作为分隔点。
- 仍以已购规格补充备注，金额识别规则不变。

## 验证

- 虚构订单覆盖不同促销名称、带空格标签、较长规格、含“价”商品名以及空规格。
- 延续无障碍优先，不增加 OCR 或重试次数。

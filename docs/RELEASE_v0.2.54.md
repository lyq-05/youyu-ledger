# 有余记账 v0.2.54

[下载 youyu-v0.2.54.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.54/youyu-v0.2.54.apk) · 通用 APK，可覆盖安装。

## 本次更新

- 淘宝同时返回完成与待付款状态时，只要实付金额明确即可打开核对面板。日期未识别时必须手选日期，再确认已付款后保存；退款、关闭和付款失败仍保留原限制。
- OCR 按同一行的实付款标题与右侧金额配对，减少优惠文案错字的干扰，不猜补金额数字或小数点。
- 京东外卖商品提取兼容外卖标记与店名合并、标记未提供无障碍文字的布局。优先填写“京东 · 外卖 · 商品名”；无障碍缺少名称时尝试 OCR 补充，失败仍保留原金额和日期。
- 修正状态冲突诊断遮盖具体解析失败原因的问题；失败时显示脱敏字段结构，便于定位。

## 验证与限制

- 61 项核心测试通过，覆盖缺少日期、状态确认、外卖商品提取和金额保护。
- 独立指南应用使用虚构数据，验证缺少日期时阻止保存、手选日期、付款确认取消不写入及确认后入账。
- 本机只读淘宝图片验证正确提取实付金额，日期留空待选择，未向账本写入图片数据。
- 手写字体可能导致 OCR 商品名错字及低置信度，低置信度名称不会自动填写，仍使用“京东 · 外卖”。无障碍能否提供完整商品名需要真机验证，不能保证每张订单都能提取。
- 已有账单备注不自动改写。

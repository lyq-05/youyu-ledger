# 有余记账 1.0.0-rc.3-diag.2

微信支付页读取修正候选包，尚未完成真机稳定性验证，不作为正式稳定版本。

基于 rc.3-diag.1，包名、正式签名和 versionCode 82 不变，可覆盖安装。未合入流水导出等其他开发中的功能。

- 支付内容延迟出现时，有限重试会刷新同一页面的事件来源节点，避免只反复读取空的窗口根节点。刷新前核对前台应用、窗口和访问代次，不拼接历史文字，不放宽支付成功、金额与返回控件校验。
- 识别反馈改为短摘要复制和完整 UTF-8 TXT 导出，避免长日志超过聊天限制。不自动发送。
- 保留临时对照诊断入口；默认关闭，手动开启后 30 分钟停止。复测本候选包时请关闭对照诊断和 OCR，以排除额外读取干扰。

验证：93 项核心测试通过。独立虚构页面先复现延迟来源丢失，修正后在诊断及 OCR 关闭时通过；不提前记账、不重复生成、离开窗口后不补记。模拟器完整页面回归运行到 OCR 截图后离开页面场景时失败，记录有系统截图错误，该项尚未通过，不宣称与改动无关。TXT 通过系统文件选择器实际保存并读回，完整结尾保留；超长摘要限长测试通过。

此前真机在 diag.1 成功一次，只能证明事件来源可提供有效信息；不能证明失败原因已完全定位，也不能推导成功率。此版需要真机复测，不要求额外线下消费。

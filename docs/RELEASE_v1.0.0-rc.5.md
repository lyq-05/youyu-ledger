## 支付宝识别

- 旧版诊断出现约200个节点、少量文字仍被读取上限拦截，定位到24层嵌套限制。调整为64层，并继续限制500节点、12000字。
- 保留输入控件排除、支付成功标记、金额歧义与历史账单排除，不以开启OCR代替修复。
- 诊断增加最深层数和具体超限原因，不记录原始页面文字；补充“交易方式”标签，例如花呗。
- 此次根据日志与虚构页面树验证；尚待真实支付宝线下消费复测，不保证所有页面都能识别。

## 账号、同步与家庭账本

- 账号页提供自动/手动个人同步切换。首次登录按登录页说明默认合并同步；同账号后续保留模式选择，不无条件覆盖本机。
- 同步账本、已入账流水、账户、预算、存钱计划和伙伴进度。图片、待确认和设备设置不上传；冲突需要确认。
- 云端数据管理区分个人同步数据与整份备份，上传本机备份与从云端恢复分别操作。恢复备份后切换手动模式。
- 家庭账本进入首页账本选择及共用记账表单，记一笔记住所选账本；每人只能修改自己的共同记录，个人账目不自动共享。
- 账号默认昵称区分手机末四位；账号入口、签到、伙伴商店布局整理。
- 家庭保存反馈区分本机保存、仍待同步、需要处理和同步完成，避免队列尚未处理完却报全部同步成功。

## 布局与交互

- 首页主入口和账号入口圆形展开；伙伴轻摇摆、头像与预览滑动联动。
- 按钮按压、输入框浮动标签、搜索与说明展开、年月网格方向变化、日历选中反馈。
- 签到、存钱进度与达成反馈；流水增删/恢复轻量过渡，删除保留确认。
- 垃圾桶使用危险红，首页眼睛使用玫紫；账号与伙伴关闭入口、头像留白和次要说明整理。
- 修复大字号与短屏适配，分类区按空间布局；金额保留白色纸面框。
- 减少动态效果开关可简化新增过渡；首次加载不为动效延迟操作。
- 月度回顾继续暂缓，正式包不开放独立虚构数据测试入口。

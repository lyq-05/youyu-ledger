## 本次更新

- 修复京东外卖“合计”规则未接入实际识别入口的问题。上一版仅底层规则支持，实际入口仍要求“实付款”，导致读到金额也无法进入核对。
- 无障碍与 OCR 的成功提示现在依据实际解析结果，避免“字段未通过校验”同时显示“识别成功”。金额缺失时保留已读到的其他字段供手动填写，不标为成功。
- 无障碍读取排除有明确边界、且位于当前窗口范围之外的节点；边界未知的节点仍按系统可见状态读取。
- 未付款诊断显示命中的固定状态词、文本段序号以及是否同时存在完成状态，不记录商品、金额、日期或订单号。

## 验证与限制

- 54 项核心测试通过；回归覆盖京东外卖实际入口（无障碍和 OCR）、普通京东支付账单、诊断一致性、退款和未付款限制。
- “退货宝、极速退款、7天无理由退货”不会触发未付款或退款拦截，已加入虚构数据测试。
- 独立指南应用验证描述节点读取京东外卖金额；没有在用户真实设备上复现节点树。
- 淘宝订单的实际误读来源仍待真机诊断确认。屏外过滤与触发词诊断不能等同于已彻底修复；仍保留明确退款、未付款及状态冲突校验。

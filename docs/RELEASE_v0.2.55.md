# 有余记账 v0.2.55

> 悬浮识别逐项填写，缺失字段手动补齐

**开发体验版** · 2026-10-12 · Android 8.0+ · 上一版 v0.2.54。

[下载 youyu-v0.2.55.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.55/youyu-v0.2.55.apk) · 通用 APK，可覆盖安装。

## 本次更新

- 主动悬浮识别按字段填写：明确金额、日期、备注等分别保留，不再因缺少日期、订单信息标题或金额而丢弃整单信息。
- 京东外卖合计识别不再要求展开支付时间。没有识别到日期时留空，由用户选择。
- 识别完成后打开核对面板；完全未识别时打开手动填写面板。缺少金额或日期时，保存按钮提示补填，不自动入账。
- 无障碍取得部分字段后，OCR 异常或未识别仍保留原字段。两路金额不一致时提示核对，不覆盖已读取的金额。
- 主动识别遇到退款、关闭或待付款状态时保留可读取字段并提示，保存前须再次核对确认。
- 通知及自动支付识别的严格校验保持不变。权限申请、锁屏等系统条件仍需满足。

## 验证与限制

- 64 项核心测试和独立指南应用无障碍读取测试通过。
- 面板集成测试被模拟器窗口焦点输入超时中断，未标记通过；真机交互尚待验证。
- 使用虚构账单验证只有金额、只有日期与商品、空内容、金额格式错误及 OCR 补充失败时的字段保留。
- 无法可靠识别的数字和低置信度商品名仍不猜填。金额和日期未补齐前不能保存。
- 本版集中调整主动悬浮识别流程，不包含分类排序。

# 有余记账 v0.2.30

> 修正相同金额新交易被页面去重拦截

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.30.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.30/youyu-v0.2.30.apk)

## 本次更新

- 页面去重改为本次前台窗口访问内有效，不再把上一笔成功页文字长期保存在本机作为拦截依据。
- 同一次停留仍避免重复弹窗；离开支付应用或切换窗口后，相同商家、相同金额可以重新识别。
- 截图识别结果绑定页面访问，离开再返回也不会接收上一次访问中尚未完成的结果。
- 判断离开仅查看前台应用包名和窗口信息；其他应用正文不进入识别。通知与页面的短时对应去重继续保留。

## 使用说明与限制

直接覆盖安装，无需卸载。识别结果仍需核对并保存才会入账。

不含订单号的成功页无法可靠区分“新交易”和“重新打开旧成功页”。重新进入旧成功页也可能再次提示，请核对后决定是否保存。

保留上一版2秒截图最短间隔；不承诺每次付款后2秒内弹窗。

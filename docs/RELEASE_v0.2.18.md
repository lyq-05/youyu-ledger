# 有余记账 v0.2.18

> 自动记账通知与小窗时序诊断

**开发体验版** · Android 8.0+ · 同包名、同签名，可覆盖安装。

[下载 youyu-v0.2.18.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.18/youyu-v0.2.18.apk) · 127.0 MB

## 本次更新

- 分组摘要独立记录，不再覆盖最近单笔账单结果；重复通知也保留上一笔结果。
- 记录系统通知发布时间、应用接收时间、小窗创建时间，以及当时应用界面在前台还是后台。
- 增加应用界面进入前台、退到后台的时间记录，最多保留最近 12 条事件，保存在本机。
- 设置 → 自动记账新增查看、复制诊断记录入口，方便反馈。诊断不记录通知原文、金额、账户或交易标识。
- 将“已打开核对小窗”改为窗口创建结果，明确系统接受窗口不代表用户当时实际可见。
- 更新诊断入口的操作指南。

## 验证与限制

23 项核心测试通过。独立指南安装以虚构通知验证前台及退到桌面后台的回调、小窗创建、重复拦截、分组摘要隔离及 12 条记录上限；查看诊断页验证通过。APK 沿用签名并覆盖安装成功。

本版用于区分通知延迟和窗口显示限制，未确认特定真机上“回到应用才出现”的根因，不宣称已经修复该现象。发布时间采用系统 postTime，不等同于实际支付时间，也可能反映通知更新。

## 下次正常消费时验证

无需专门付款测试。完成消费后先回手机桌面停留约 30 秒，暂不打开有余；观察小窗是否出现，再进入有余。将“设置 → 自动记账 → 复制诊断记录”的文字与观察结果一起反馈。

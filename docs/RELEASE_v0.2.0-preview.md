## 🚀 本次更新

1. 补齐月、年和自选日期统计、分类预算、存钱计划归档与恢复。
2. 支持本地图片 OCR 补记、自定义 CSV 模板导入、完整本地备份恢复，以及快捷记账、收支预算、存钱愿望三种桌面组件。
3. 转账、提现手续费单列支出；还款本金、手续费和优惠分别处理。跨月退款按退款日冲减支出。
4. 同阶段完善主动悬浮识别历史账单、图文指南、统一图标和内页样式。多个预览构建沿用版本号，未据此虚构独立版本。

## ⚠️ 使用与升级说明

当前为开发体验版，使用调试签名。真实支付通知、页面读取、厂商后台策略及动画真机流畅度、耗电和温升仍需验证。识别结果需要核对后入账；自定义 CSV 导入不等于兼容支付宝或微信的原始导出文件。

同签名体验版可覆盖安装。升级前请导出本地备份；不要直接卸载来解决签名冲突。

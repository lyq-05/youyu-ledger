# 有余记账 v0.2.63

> 拼多多无障碍实付格式适配

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.62。

[下载 youyu-v0.2.63.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.63/youyu-v0.2.63.apk) · 可覆盖安装。

## 本次更新

- 支持拼多多无障碍实付字段在标题、金额、免运费说明之间使用逗号分隔，直接读取原始数字。
- 仅在拼多多无障碍通道适配该格式；不删除数字内部逗号，不猜测 OCR 缺失的小数点。
- 拆分同一节点内紧贴商品规格的数量、价格和优惠标签，避免整段明细混入备注。
- 字段诊断保留与商品文字连写的已购规格及价格标签，商品文字仍脱敏。
- 已读取的下单日期继续保留并提示确认。

## 验证与限制

- 75 项核心测试通过，覆盖逗号分隔、连写规格、整数金额、异常格式和金额冲突。
- 回归使用虚构数据复现字段结构，未写入用户账本。
- 本次定位并修复已收到诊断中的格式问题；其他滚动位置及商品备注仍需真机验证。

# 有余记账 v0.2.59

> 淘宝商品备注按当前截图定位，并用匹配的页面文字补全

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.58。

[下载 youyu-v0.2.59.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.59/youyu-v0.2.59.apk) · 可覆盖安装。

## 本次更新

- 淘宝商品备注不再仅依赖店名包含“商店、旗舰店”等词；新增商品标题、规格与实付价附近的位置识别。
- OCR 标题清楚时直接填写；较低置信度的标题仅用作匹配依据，不直接当作可靠商品名。
- 无障碍名称须与当前截图标题有足够长的一致片段，且只有一个匹配候选，才能补充备注。
- 无障碍补充不更改截图金额、日期及订单标识，不匹配或有歧义时保留截图结果。

## 验证与限制

- 69 项核心测试通过，覆盖无店名后缀、低置信度、旧商品不匹配、相似候选冲突、金额日期不被补备注改变。
- 只读截图检查确认金额读取正确，同时发现手写商品标题存在错字；未写入账本。
- 尚未取得真机当前页面节点，不能确认这张订单一定能补全。节点未提供对应标题或截图文字过于模糊时，仍需手动填写。

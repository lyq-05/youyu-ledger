# 有余记账 v0.2.13

> 安装包瘦身、记账提速与悬浮识别排查

**开发体验版** · Android 8.0+ · 与 v0.2.12 同包名、同签名，可覆盖安装。

## 本次改动

- 移出 14 张确认未引用的旧素材，原文件保留在私有源码的素材归档中；没有删除现有功能代码、识别库或手机架构支持。
- 23 张操作指南图片改为无损 WebP，逐张验证像素一致。安装包由 159.1 MB 降至 124.0 MB，减少约 35.2 MB。
- 记账按键共享纹理像素，避免重复解码；模拟器同条件首次打开的最长帧由约 2.84 秒降至 0.52 秒。此为单次前后对比，不代表所有手机的响应时间。
- 桌面图标改为黄粉彩铅书本与叶片，保留阳光、亮边及投影。
- 点击悬浮松鼠时，若已开启无障碍，先尝试读取当前支付页面的账单文字；读取不到再走截图 OCR。无障碍仍为可选，未开启时保持截图识别。
- 屏幕共享连接画面后等待短暂稳定，再读取最新帧；区分无文字、账单字段校验失败、识别异常和超时。
- “设置 → 权限与识别状态 → 最近状态”增加悬浮识别诊断，只保留尺寸、明暗差、字数、耗时和阶段，不保存截图或识别出的账单正文。

## 验证与限制

20 项核心测试、合成双列账单 OCR 通过。模拟器通过真实屏幕共享对静止合成账单连续识别两次，并确认非账单页面不会沿用上一笔结果。指南图片显示正常，包名、版本与签名已核验。

**微信实时账单页失败、同图在微信图片查看器成功的真机差异尚未确认根因，也未宣称已修复。** 本版改进取帧与读取路径并补充诊断，需继续实机验证。手写小字、日期、账户仍可能误识别；所有结果请核对后入账，历史账单缺失日期时默认今天，需要修改。

升级前建议导出本地备份，直接覆盖安装，不必卸载。自动通知识别仍需不同手机实测。

## 本次重点复测

1. 在微信历史账单详情点击松鼠，再在微信图片查看器打开同一张截图、点击松鼠，对比两种结果。
2. 若失败，请记录“权限与识别状态”中的“最近悬浮识别”文字，以及是否已开启无障碍。无需提供完整订单号。
3. 检查首页首次打开“记一笔”的速度，以及新桌面图标。

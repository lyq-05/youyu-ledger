## 本次更新

- “设置 → 基础”新增 **深色主题（测试）** 开关，普通体验版也可使用暖灯夜景首页及深色内页。
- 默认保持浅色。开启后立即切换，选择保存在本机，重启应用后继续生效；关闭即可恢复浅色。
- 在进程启动时恢复主题，使后台服务先启动的情况下也能读取主题选择。

## 验证与已知限制

编译和安装包身份检查通过；模拟器检查开关切换、进程重启后保留选择及关闭恢复浅色。安装包签名与上一版一致。

深色主题仍是测试功能，各页面、弹窗、文字对比度和不同手机显示效果尚未完成全面验收。本次不新增自动记账渠道，不改变银行通知规则；此前待真机验证的场景继续保留。

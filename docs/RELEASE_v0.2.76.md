# 有余记账 v0.2.76

## 本次更新

- 减少记账面板之外的厚重粉色底材按钮，月份、预算、备份、账本选择、筛选和账单操作改用文字、图标或轻边框；保留删除确认及明确的危险操作颜色。
- 记账数字面板与悬浮核对面板保留原有操作样式。
- 指南图片放大后提供固定在右上角的 X 关闭图标。
- 更新操作指南的 27 张截图与 32 个图文页面，补充流水筛选、账单详情及预算说明，对齐当前按钮和入口位置。
- 更新京东、京东外卖、抖音商品与团购示例，加入微信、支付宝账单图片。个人信息和交易编号逐块遮挡，保留操作所需的页面结构。
- 抖音指南提示切换系统默认字体有助于 OCR 稳定识别；微信、支付宝示例无需展开，也不强求页面没有的商品备注。

## 验证与限制

- Release 构建、85 项核心测试通过；安装包身份、版本及与上一版签名一致性已核验，测试工具关闭。
- 独立指南应用中已验证图片 X 关闭、主题内连续滚动及切换主题回到顶部；指南截图使用虚构账本数据。
- 本版主要更新界面和说明，不代表解决第三方应用所有无障碍文字缺失问题。OCR 是补充方式，金额、日期与备注仍需保存前核对。

# 有余记账 v0.2.20

## 本次更新

- 支付成功页识别同时读取可见控件文字和无障碍描述，去除同一控件重复的文字/描述。
- 首次读取后未匹配时，最多再读取两次，兼容金额延迟加载；窗口已切换时不继续读取其他应用。
- 新增独立「最近页面读取」记录，说明窗口是否取得、读取次数、节点/文字/描述数量，以及输入页、历史页、成功标记、完成控件或金额不匹配等结果。
- 复制诊断包含页面结果，不记录页面原文、金额及账户。相同短时状态限频记录，历史仍最多 12 条。
- 更新诊断操作指南。保留显式开关、渠道控制及先核对后入账。

## 验证与限制

25 项核心测试通过。独立指南安装使用虚构页面验证无障碍描述文字、延迟金额、小窗、历史页/输入页拒绝、重复页面与新访问、开关和双向去重。诊断不含样本金额；签名核验与覆盖安装通过。

这是针对已发现代码缺口的修正与诊断增强，尚未确认用户真机微信支付失败的具体原因，也不宣称所有微信成功页已支持。截图无法代替无障碍页面测试；真实应用可能不开放文字或提供不同结构，纯图片仍需主动悬浮 OCR。

## 如何反馈

保持总开关、支付成功页识别和微信渠道开启，无障碍显示已连接。后续正常消费若仍未弹窗，在设置 → 自动记账复制诊断记录反馈；无需专门反复付款测试。即使未消费，打开微信后也可查看是否出现页面读取记录，只用于确认事件和文字通路，不代表支付识别已通过。

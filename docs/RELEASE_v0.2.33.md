# 有余记账 v0.2.33

> 事件来源识别与字段缺失诊断

**开发体验版** · Android 8.0+ · 上一版 v0.2.32，同签名覆盖安装。

[下载 youyu-v0.2.33.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.33/youyu-v0.2.33.apk)

## 本次更新

- 窗口根没有可读取文字时，尝试同一前台支付窗口的事件来源节点及描述。无需开启调试开关；关闭OCR时也可使用此入口。
- 原窗口包含输入控件、文字或读取截断时，不使用局部来源绕过检查；仍要求完整支付成功标记、金额及完成/返回控件。
- 无障碍对照诊断新增独立成功标记、内含成功字样、返回控件、金额行/片段数量及拒绝原因，不记录商户、金额或描述正文。
- 同一次窗口访问中，同金额的节点和OCR结果共用去重，避免不同文字表示导致重复弹窗。离开并进入新的支付访问后不沿用旧访问的去重。

## 如何验证

在“设置 → 自动记账”开启支付成功页识别、微信渠道和无障碍服务。排查时可暂时关闭OCR，并打开“无障碍对照诊断（调试）”；下次正常消费后复制诊断记录，随后关闭调试开关。

该版本接入此前遗漏的读取入口，不保证原先62字描述就包含完整付款信息。真实微信兼容性仍待验证；OCR兜底和已接收截图离页处理保留。

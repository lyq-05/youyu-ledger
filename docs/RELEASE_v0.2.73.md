# 有余记账 v0.2.73

> 抖音团购实付与商品备注解析优化

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.72。

[下载 youyu-v0.2.73.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.73/youyu-v0.2.73.apk) · 可覆盖安装。

## 本次更新

- 普通抖音和独立抖音商城支持团购同一行的“原价 × 数量 实付金额”，只提取明确标注的实付。
- 商品备注结合订单内商品标题形态及 OCR 置信度提取，排除服务标签和推荐区域；多候选或低置信度时留空。
- 排除“本店更多团购”“小伙伴们还喜欢”等区域，不将推荐商品价格或标题作为当前订单。
- 日期不在当前画面时保留已识别金额、备注，仍由用户确认日期；不跨屏拼接订单。

## 验证与限制

- 84 项核心回归测试通过，覆盖同行实付、推荐价格、缺小数点、低置信度备注及日期缺失。
- 无障碍优先流程保持；抖音页面没有返回订单正文的问题尚未解决，本次优化作用于已有文字与 OCR 补充结果。
- 手写体 OCR 的错字及漏识别仍需在保存前核对，尚需用户手机实测。

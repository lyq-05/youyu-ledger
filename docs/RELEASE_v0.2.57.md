# 有余记账 v0.2.57

> 简化分类排序操作，补充淘宝订单合计识别

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.56。

[下载 youyu-v0.2.57.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.57/youyu-v0.2.57.apk) · 通用 APK，可覆盖安装。

## 本次更新

- 分类排序去掉每行成排的粉色立体按钮，改为无底色文字和箭头，保留置顶、上移、下移及恢复默认功能。
- 主动识别淘宝订单时，支持“合计”金额标题；明确的整单合计优先于页面其他位置的实付字段。
- OCR 同行合计标题与右侧金额配对，兼容观察到的手写字体标题、货币符号误读，不改动数字和小数点。
- 多个合计金额相互冲突时仍提示手动核对；日期缺失留空，状态冲突保留确认提示。
- 商品备注排除“交易成功”“交易完成”“待付款”等状态文字。

## 验证与限制

- 66 项核心测试通过，覆盖整单合计优先、优惠金额干扰、多个合计冲突、状态备注排除和 OCR 字形兼容。
- 独立指南应用检查排序界面，行内粉色按钮底材已去除。
- 本机只读截图复测正确提取合计金额，未写入任何账单；完整真机页面仍需实际核对，日期和商品名可能需要手动补填。

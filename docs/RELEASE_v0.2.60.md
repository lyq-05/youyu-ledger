# 有余记账 v0.2.60

> 修正拼多多备注字段，改善淘宝手写标题匹配

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.59。

[下载 youyu-v0.2.60.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.60/youyu-v0.2.60.apk) · 可覆盖安装。

## 本次更新

- 拼多多优先使用明确的“已购规格”商品文字，不再把分享商品、联系商家等操作按钮填入备注。
- 淘宝商品位置判断排除规格和操作行，支持实付款附近的标题定位。
- 手写标题匹配允许少量分散错字；低置信度仅作为匹配依据，仍须有唯一的对应无障碍商品名。
- 金额、日期及订单标识不因商品名补充而改变；多个相似候选继续留空。

## 验证与限制

- 71 项核心测试通过，覆盖拼多多规格、操作文字排除、手写错字及相似商品冲突。
- 淘宝只读截图测试正确读取金额，并找到可用于匹配的标题片段。
- 拼多多只读截图 OCR 仍有明显错字；本次主要改善无障碍字段选择，不能保证仅截图即可完整识别。
- 尚无真机页面节点原文，实际商品备注成功率仍需安装后验证。测试未写入用户账本。

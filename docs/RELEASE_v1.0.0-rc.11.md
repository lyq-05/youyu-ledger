# 有余记账 v1.0.0-rc.11

在账单导入页新增“微信／支付宝历史账单如何下载？”文字指引，默认收起，点击展开。

- 列出微信与支付宝的下载路径，说明支付宝“开具交易流水证明 → 用于个人对账”也是历史账单导出入口。

- 包含 rc.10 的原始账单文件导入、预览和同来源去重，以及 rc.9 的旧系统启动修复。本次未改动解析规则。
- 退款、还款、不计收支等仍需另行处理；与手工或自动识别账目不能保证跨来源去重。

正式包名、签名及数据库版本不变，可覆盖升级。版本号 90，最低 Android 8.0（API 26）。

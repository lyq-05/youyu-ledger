# 有余记账 v0.2.28

> 微信支付截图 OCR 容错修正

**开发体验版** · Android 8.0+ · 同签名，可覆盖安装。

[下载 youyu-v0.2.28.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.28/youyu-v0.2.28.apk)

## 本次更新

- 修正微信截图 OCR 将手写“支付成功”误读为“支付成中”、漏读金额前货币符号时，被成功页规则拒绝的问题。
- 容错仅用于微信截图 OCR。无货币符号时，金额必须独占一行、含两位小数且为正数；仍要求成功标记和返回商家/完成标记，排除历史详情、失败、退款及多金额歧义。无障碍文字规则不放宽。
- 金额是否带货币符号不会单独改变截图去重标识。
- 最近截图结果和已保留截图显示具体失败原因，不再只显示“未匹配支付成功页”。
- 保留上一版可选的本机截图调试，默认关闭，关闭即清除。

## 验证与限制

本机只读 OCR 诊断复现了标题误读和货币符号漏读，修正后同一完整页面可解析。虚构规则测试覆盖误读、漏符号、非法金额、失败/待支付/退款、历史详情、多金额及去重。

此结果不等于所有手机和微信版本均已验证。截图显示正确也可能有 OCR 错字；后续可结合具体拒绝原因定位。识别后先弹出核对，保存后才入账；多多支付尚未接入。

无需卸载，直接覆盖安装。无需专门消费测试，后续正常消费时再验证即可。

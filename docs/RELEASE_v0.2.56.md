# 有余记账 v0.2.56

> 分类自由排序，修复淘宝实付款读取

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.55。

[下载 youyu-v0.2.56.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.56/youyu-v0.2.56.apk) · 通用 APK，可覆盖安装。

## 本次更新

- 设置 → 分类管理支持置顶、上移、下移和恢复默认顺序。记一笔内的分类管理也可调整。
- 支出、收入分别保存排序，普通记账与悬浮核对共用，重启后保留，并随本地备份导出、恢复。
- 修复淘宝实付款区域中货币符号被 OCR 读成字母、优惠解析标签错字时的金额读取。仅在实付款字段及明确小数金额范围内处理，不猜数字或补小数点。
- 金额未识别时显示具体解析原因；仍保留其他已知字段并打开核对面板。

## 验证与限制

- 65 项核心测试通过，覆盖优惠金额干扰、货币符号错读、小数点缺失、不同实付款冲突。
- 独立指南应用验证排序持久化、收支独立、恢复默认、新增分类、备份恢复，以及旧版数据库与备份迁移。
- 实际界面验证将购物置顶后，普通记账分类首位随即更新。
- 本机只读截图复测提取金额成功；没有将图片中的账单写入账本。商品名、日期仍可能需要手动补填，真机效果以核对结果为准。

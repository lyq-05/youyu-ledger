## 🚀 本次更新

1. 首次进入首页弹出操作指南提示，可查看或忽略，使用森林绿、奶油纸面与花草边角。
2. 点击查看指南后不叠加权限提示；返回首页后，才按实际缺少的权限提示配置。直接忽略指南则继续显示权限提示。
3. 权限引导可选择以后再说，不开启也能手动记账。选择保存在本机，重启不会重复已处理的提示；尚未处理的第二步会保留。
4. 指南、入账编辑、账本和月份弹窗、图片分享及组件入口期间不显示首次引导。已完成旧版指南引导的用户不重复弹出。
5. 项目主页补充功能、权限说明与版本主题表，按现存记录整理历史版本说明。

## ⚠️ 使用与升级说明

当前为开发体验版，使用调试签名。真实支付通知、页面读取、厂商后台策略及动画真机流畅度、耗电和温升仍需验证。识别结果需要核对后入账；自定义 CSV 导入不等于兼容支付宝或微信的原始导出文件。

同签名体验版可覆盖安装。升级前请导出本地备份；不要直接卸载来解决签名冲突。

## 首次引导顺序

| 用户操作 | 现在的行为 |
| --- | --- |
| 查看指南 | 安静阅读指南，返回首页后再提示权限 |
| 忽略指南 | 留在首页，继续提示权限 |
| 以后再说 | 不请求权限，仍可手动记账 |
| 现在去设置 | 打开权限与识别状态，按需配置 |

## 本次更新

- 设置→基础开放云账号：手机验证码注册、密码登录/找回、昵称头像、修改密码、退出及注销。登录不自动上传个人账本。
- 手动云备份提供上传、下载恢复及删除；不含图片，每账号保留最新一份。恢复前确认覆盖范围并保存本地安全副本。
- 设置→基础新增家庭账本：创建或凭一次性邀请码加入；共同查看收支，各人只能修改/删除自己的记录，创建者邀请或移除成员。
- 家庭账本独立记录收支，进入账本或主动保存/刷新时同步；离线记录先留本机，冲突不直接覆盖。个人账本及自动识别记录不会自动共享。首版不含共享图片、资产余额、转账和退款。
- 保留此前诊断候选的微信无障碍事件来源重试改进，以及短摘要/完整TXT反馈导出；不更换OCR引擎、不放宽支付成功页校验。
- 更新隐私说明与备案号：粤ICP备2026158504号-3A。暂停中的月度回顾不开放正式入口。

## 验证与限制

- 用户已在模拟器成功完成真实短信注册。
- 53项服务端测试、95项核心测试通过；Android虚构双账号HTTPS联调通过，包括云备份恢复、作者权限、移除成员、冲突处理、25笔离线待同步分批提交和重新登录隔离。
- 正式构建、关键静态检查、签名、16KiB ZIP对齐及独立模拟器覆盖安装通过。实际家庭成员跨设备协作和公网云备份恢复仍待用户试用，不等于已完成全场景真机验证。
- 短信服务仍处于小规模试用限制：本服务每日最多15次、每月150次发送尝试，可能提示额度不足；普通密码登录不发送短信。不适合据此直接进行大规模推广。
- 退出或被移除后已同步共同账目保留；创建者解散会删除整个共同账本。离线设备可能暂存旧内容，联网核验成员资格后清除。
- 微信线上和线下支付已有用户成功反馈，但不同设备/系统/支付页面仍可能漏识别；银行卡渠道真机覆盖有限。识别结果始终需要核对。

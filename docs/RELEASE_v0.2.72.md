# 有余记账 v0.2.72

> 独立抖音商城悬浮识别入口修复

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.71。

[下载 youyu-v0.2.72.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.72/youyu-v0.2.72.apk) · 可覆盖安装。

## 本次更新

- 补上独立“抖音商城”App 的无障碍窗口适配；此前只登记普通抖音，独立商城会被判为其他应用，无法进入订单读取。
- 保持无障碍优先，沿用订单实付、日期和商品解析规则。
- 来源无法确认的购物截图不再套用支付宝账单规则，避免把负号优惠金额识别成支出。

## 验证与限制

- 82 项核心测试及模拟器无障碍窗口读取检查通过，覆盖独立商城、实付与优惠区分、团购日期及推荐商品排除。
- 尚需真实手机验证独立商城暴露的商品节点；本次修复入口，不保证所有订单备注均能读取。
- 团购若只显示下单时间，日期仍需确认；手写体 OCR 结果仍需核对。

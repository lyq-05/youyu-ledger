# 有余记账 v0.2.21

> 修正不可见父节点导致的页面漏读

**开发体验版** · Android 8.0+ · 同包名、同签名，可覆盖安装。

[下载 youyu-v0.2.21.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.21/youyu-v0.2.21.apk) · 127.1 MB

## 本次更新

- 无障碍父节点标记不可见时，继续遍历其子节点；仅采集可见节点自身的文字和描述。
- 保留密码/输入控件排除与读取数量限制，不加入自动截图或 OCR。
- 页面诊断增加根节点可见性、根子节点数、不可见节点数、无法取得的子节点数。

## 验证与限制

独立 guidecapture 安装使用虚构数据，验证不可见父容器下的可见支付文本能触发核对小窗，父容器隐藏的干扰金额没有进入解析。同时通过历史/输入页拒绝、描述文字、延迟金额、重复及新访问、开关与去重回归。APK 签名核验和覆盖安装通过。

已修复一处确定的遍历缺口，但尚未证明这就是特定真机微信成功页读到零文字的原因。真实页面可能确实不提供子节点，需后续诊断确认。不需要专门付款测试，等待正常消费即可。

## 诊断反馈

若仍未弹窗，请在设置 → 自动记账复制诊断记录；根节点可见性和子节点数量可帮助区分提前停止、空节点树与节点不可取得。历史账单仍被跳过，不会自动入账。

# 有余记账 v0.2.51

## 本次更新

- 悬浮购物账单重复时提供“仍然入账”确认，新增一笔记录；已删除或彻底删除的记录也不再永久阻断主动补记。取消确认不会新增记录，自动识别去重仍保留。
- 将主动无障碍读取移至独立工作线程；约 2.5 秒未返回则转 OCR，忽略迟到结果，避免随后重复弹窗。窗口状态观察使用事件信息，减少界面线程跨应用读取。
- 京东外卖已完成订单支持“合计”字段，要求完成状态、支付时间及外卖相关字段，不直接使用商品总价。
- 淘宝等订单状态改为匹配明确状态文字，不再因说明句中包含“待付款”等词就直接拒绝；明确退款、未付款或冲突状态仍需手动核对。

## 验证与限制

- 50 项核心测试通过，包含京东外卖合计、未付款防误识别及说明文字中的状态词。
- 独立指南应用用虚构数据验证保存、取消重复确认，以及彻底删除后明确确认重新入账。
- 发布构建通过。点击延迟的线程阻塞路径已修正，真实设备上的偶发行为及平台完整页面仍需复测。
- 淘宝诊断证实被未付款规则拦截，但未取得原始节点文字；本轮修复整页子串误判，不能保证已覆盖全部节点格式。

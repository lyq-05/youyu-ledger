# 有余记账 v0.2.16

> 设置分类导航与首页细节调整

**开发体验版** · Android 8.0+ · 同包名、同签名，可覆盖安装。

[下载 youyu-v0.2.16.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.16/youyu-v0.2.16.apk) · 125.7 MB

## 本次更新

- 设置顶部固定六类导航：基础、自动记账、悬浮记账、备份恢复、数据导入、关于。分类栏支持横向滑动；分类分别保留滚动位置，从管理页返回原设置分类。
- 基础设置新增字号，默认跟随系统，可选小、标准、大、特大，即时预览；应用内文字与新打开的悬浮面板使用该设置。插画内文字不缩放。
- 自动记账、悬浮记账分别展示对应权限、渠道与最近识别状态。悬浮备注可选高置信度自动填写或始终留空。
- 移除旧的 90 秒等待读取入口和专用流程，保留主动悬浮识别的无障碍文字读取与屏幕 OCR。即时消费通过自动记账，历史账单通过悬浮记账，文件与图片补记集中在数据导入。
- 首页招牌使用透明书本叶片图标，清除旧图标与圆形白底；设置齿轮改为暖色彩铅。书页高光覆盖顶部并减弱强度，保护钢笔轮廓。
- 更新首页、设置、自动记账及悬浮记账指南截图和说明。测试入口仅用于独立指南安装。

## 验证

23 项核心测试通过。独立指南应用验证六类入口、字号实时预览、账户/图片补记/指南返回、备注策略保存，以及标准/特大字号的悬浮面板、保存与取消。指南及公开截图全部使用虚构数据。APK 覆盖安装成功，仍需不同真机字体、屏幕尺寸与权限环境验证。

备注高置信度门槛保持 0.90，不代表正确率保证；需要时可选择始终留空。本版未新增云端服务。

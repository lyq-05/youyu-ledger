# 有余记账 v1.0.0-rc.9

修复 Android 8–9 的数据库关闭兼容问题。此前启动时调用数据库 `use`，依赖 Android 10 才加入系统 SQLiteOpenHelper 的 AutoCloseable 接口，导致部分旧系统在进入首页前崩溃。现在由应用数据库类显式实现 Closeable。

- 保持正式包名、签名和数据库版本不变，可覆盖升级；无需卸载或清空账本。
- 本次未改动识别规则、云同步、账号或权限用途。
- 未修改的 rc.8 已在 Android 9 模拟器复现 vivo X27/S1 相同异常；rc.9 进入首页、冷启动与后台返回均通过。
- 数据库正常退出与异常退出关闭测试在 Android 9、Android 16 通过；96 项核心测试通过。
- 尚未完成 X27/S1 云真机复测；本包尚未重新进行 vivo 隐私/兼容测试，也未重新提交商店审核。

版本号 88，最低 Android 8.0（API 26）。

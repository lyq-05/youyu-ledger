# 有余记账 v0.2.64

> 拼多多无障碍正文缺失重读与诊断

**开发体验版** · 2026-10-13 · Android 8.0+ · 上一版 v0.2.63。

[下载 youyu-v0.2.64.apk](https://github.com/lyq-05/youyu-ledger/releases/download/v0.2.64/youyu-v0.2.64.apk) · 可覆盖安装。

## 本次更新

- 拼多多无障碍仅读到少量文字且没有金额时，等待250毫秒，在同一应用窗口刷新并重读一次，再决定是否补充 OCR。
- 窗口变化时丢弃本次读取，不合并旧结果，不读取隐藏页面。
- 诊断新增遍历节点数、不可见节点数、缺失子节点数、窗口及读取次数，区分正文缺失与字段解析失败。
- 已稳定读取的订单不增加重试等待。

## 验证与限制

- 核心回归及独立指南应用的读取检查通过，覆盖稀疏正文、已读金额、窗口选择和不可见节点。
- 本次针对仅取得少量页面文字的情况补充重读和结构诊断；尚不能确认目标页面是否始终向无障碍提供正文。
- OCR 仍只作补充，不放宽金额判断，不通过读取其他窗口解决正文缺失。

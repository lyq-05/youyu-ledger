# 有余记账 v1.0.0-rc.13

历史账单导入支持明确规则自动分类和批量核对入账。

- 导入确认按钮固定在底部，不再需要滚到预览末尾。
- 支出中拼多多平台订单可归购物；API 服务、绿钻及明确的订阅描述归订阅；支付宝部分明确交易分类转换为应用分类。未知内容保留待分类，收入不会套用支出规则，所有分类均可修改。
- 待确认按导入批次显示，可勾选、全选本批、自动补齐待分类项、批量修改分类，并在汇总笔数／收入／支出后一次入账。
- 同账本已有同日同额同方向流水时提示可能重复，全选默认跳过这些记录，可逐笔勾选并核对。此提醒不等同于精确跨来源去重。
- 预览和导入待确认列表收起纯订单号，原有备注仍保留，可点击记录核对。文件缺失的商品内容不推测生成。
- 旧导入记录按来源分组，支持同样的批量操作。入账可保留待分类；批量分类当前针对导入待确认记录。

版本号 92，正式包名和签名不变，最低 Android 8.0，可覆盖升级。数据库升级为 17，新增本机导入批次元数据；账本、流水等保留。批次信息不随云同步或账本备份传输，恢复的导入待确认记录按来源分组。无需重新导入已存在的待确认记录。

验证：102 项核心测试通过；Android 9 独立指南测试覆盖同库锁冲突、导入去重、分类修改、批量入账中途失败整批回滚、过期核对／重复提交拦截、可能重复提醒、schema 16→17 升级；模拟器真实点击操作完成 4 笔虚构账单自动分类、汇总核对及批量入账。Release 构建、关键 Lint 和签名验证通过。未重新提交 vivo 审核或云测。

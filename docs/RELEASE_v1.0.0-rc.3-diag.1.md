# 有余记账 1.0.0-rc.3-diag.1

仅用于微信支付页无障碍读取问题的临时排查，不是修复版，不建议普通用户安装。

基于 rc.3 源码；正式包名、签名和 versionCode 82 不变，可覆盖安装 rc.3，也可用 rc.3 覆盖返回。不卸载、不迁移账本。

仅增加独立的“无障碍对照诊断（调试）”入口，不开放其他测试工具。位于设置 → 自动记账 → 更多设置与帮助；默认关闭，手动开启后 30 分钟停止，关闭清除应用内记录。最多保留 300 条结构摘要；记录窗口、节点数量、文字长度、可见性、匹配结果及服务配置，不保存页面正文、金额或截图。诊断摘要也输出到设备日志，便于 USB 现场采集；关闭开关不清除已采集的电脑日志。

识别规则、读取选择逻辑、OCR 默认状态、服务声明与 rc.3 一致。诊断会增加额外读取，因此本包用于定位，不作为性能或识别成功率结论。

测试时保持 OCR 关闭。先验证普通微信页面的结构记录，再进行一次支付测试；支付完成后保留成功页，告知测试完成，由研发采集诊断。无需提供支付密码或验证码。

验证：93 项核心测试通过；识别源文件及无障碍声明与 rc.3 一致；正式签名 SHA-256 与 rc.3 相同。现场读取问题尚未解决。
